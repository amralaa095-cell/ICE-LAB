!Safety first
  • Know where the emergency stop is before you start.
  • Never leave the chuck key in the chuck.
  • Never reach into the machine while a program runs.
  • Always do a dry run of a new program.
  • No gloves, loose sleeves, jewellery or open long hair.

M-08 · Steps 1–6
Set up and load
Circle = zoomed side view
Red border = stop and check
1
Gear up
Glasses on, hair tied, sleeves up, closed shoes. Take off gloves, rings and watch.
2
Clamp the bar
Max 3× its diameter sticking out. Tighten at key holes 1, 2 and 3.
3
Tool at centre height
The tool tip must sit exactly on the centre line of the part.
4
Key out, turn by handCHECK
Remove the chuck key. Turn the chuck one full turn: nothing should hit.
5
Set the work zero
Touch the tool on the end face: that is Z0. X is the diameter.
6
Load the program
Open your G-code and read it once: units, speed, first move.

M-08 · Steps 7–9
Run, measure, finish
Circle = zoomed side view
Red border = stop and check
7
Dry run, clear of the partCHECK
Move the tool well away in X and run once. Watch the path.
8
Run, hand on E-stop
Start the program and stay at the machine, ready to stop.
9
Stop, measure, clean
Wait for a full stop, measure, then brush the chips away.
If something goes wrong
Tool heads the wrong wayE-stop. Check the work zero and the units
Cuts too deepE-stop. Re-set Z0 on the top face
Program will not startCheck the controller is on and E-stop released
Strange noise or smellE-stop, call a technician
Before you leave
Spindle and controller off
Cutter removed and returned
Chips brushed into the bin
Your G-code file saved
Booking marked as finished
Book again & try the simulator
